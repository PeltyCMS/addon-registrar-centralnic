# CentralNic Reseller

Register and renew domains with CentralNic Reseller

Official domain registrar for [PeltyCMS](https://github.com/MythicalLTD/PeltyCMS).

## Why this addon

Resellers who sell domains next to hosting and need automated register / renew.

## Features

- Availability checks against the official **CentralNic Reseller** API
- Register, renew and transfer domains from Pelty orders
- Nameserver and contact updates where the API allows
- TLD costs sync into Pelty pricing
- Sandboxed WASM registrar — credentials stay in the panel

## How it works

1. Install **CentralNic Reseller** from the [Mythical marketplace](https://market.mythicalsystems.org/marketplace/product/registrar-centralnic) inside Pelty Admin → Addons.
2. Open Pelty Admin → Domains, connect CentralNic Reseller, sync TLDs, and sell domains like any other product.
3. Customers hit checkout / login / order flow as usual — CentralNic Reseller runs in the background.

## Requirements

- PeltyCMS with WASM addons enabled
- Working CentralNic Reseller credentials
- Outbound HTTPS from your panel
